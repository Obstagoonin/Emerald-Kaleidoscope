Pokémon Emerald Kaleidoscope — v1.0 Public Beta

A customizable Pokémon Emerald randomizer with built-in Nuzlocke mechanics, quality-of-life improvements, and expanded Pokémon content.

Pokémon Emerald Kaleidoscope is a ROM hack built using the pokeemerald-expansion project. It aims to make every playthrough feel different while giving players control over how they experience Hoenn.

Instead of relying on external randomizer programs, Kaleidoscope includes its own randomization settings directly in the game.

Features

* Built-in Randomizer: Customize your experience when starting a new game.
* Integrated Nuzlocke Mode: Optional Nuzlocke rules with automatic tracking and permanent save deletion when your run ends.
* Automatic Saving: Built-in autosave functionality.
* Seed System: Generate randomized playthroughs and replay previous seeds.
* Expanded Pokémon Content: Built on pokeemerald-expansion, offering additional Pokémon, moves, abilities, and mechanics.
* Quality-of-Life Improvements: Modernized features designed to make repeat playthroughs more enjoyable.
* Customizable Challenge: Adjust your experience using the in-game settings.

Public Beta

This is the first public release of Emerald Kaleidoscope. Although several core systems have been tested, bugs and balancing issues may still exist.

Player feedback is highly encouraged! A bug report form is included in the download alongside the player guide.

Installation

1. Obtain your own clean English Pokémon Emerald (USA) ROM.
2. Download and extract the release ZIP.
3. Apply the included .bps patch using RomPatcher.js.
4. Open the patched game in a compatible GBA emulator.
5. Start a new game and configure your settings.

The download contains a patch, not a complete Pokémon ROM.
